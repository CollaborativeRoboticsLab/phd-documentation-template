# Contribution 1

This contribution centres on Capabilities2, a ROS2 framework for representing, querying, and executing robot capabilities in a form that is suitable for human-robot interaction (HRI) and higher-level task control. The finalized source for this material is the Capabilities2 paper, which reframes the original ROS Capabilities package for contemporary ROS2 systems and extends it to support more adaptable skill-based control.

In HRI, robots must expose their skills in ways that are understandable to both people and software systems. Existing approaches range from rigid, symbolic representations to more flexible but weakly grounded models, and they often struggle to balance standardisation, extensibility, and deployment practicality \cite{chen2024language, olivares2019review}. This creates a persistent gap between lower-level robot subsystems and higher-level control layers that need to answer questions such as what a robot can do, how a skill should be invoked, and how those skills can be composed safely.

The first contribution of this thesis addresses that gap by reimplementing the original ROS(1) Capabilities package in ROS2 and extending it with a more flexible execution and data-management architecture. Capabilities2 introduces an abstracted database handler, an object-relational mapping (ORM) approach for capability models, and a plugin-based runner architecture for capability execution. These changes shift the package from a static capability description mechanism toward a practical substrate for skill-oriented planning, runtime adaptation, and reusable robot interfaces.

The wider thesis chapter extends beyond the finalized paper manuscript. In the earlier thesis draft, the Capabilities2 framework was positioned alongside two additional subsystems: Prompt Tools, a ROS2-oriented interface layer for communicating with large language models, and Capabilities2 Fabric, a planning and execution layer that parses execution plans and coordinates capability chaining. The later GPSFSM paper then developed this broader stack more explicitly by presenting Fabric as a Generative Partially Specified Finite State Machine framework and PromptTools as the LLM-facing service layer used to support plan generation, validation, and execution.

This chapter therefore positions Contribution 1 as both an infrastructure contribution and a systems-integration contribution for the wider thesis. It establishes a standardised capability layer that can support richer planning systems, improve portability across robot platforms, and provide a bridge between symbolic robot skills and newer AI-assisted planning methods. The following sections review the motivating literature, describe the Capabilities2 design, incorporate the thesis-specific and GPSFSM-derived Fabric and Prompt Tools material, discuss both the system architecture and the reported evaluation results, and summarise the implications of this contribution for the broader research program.
