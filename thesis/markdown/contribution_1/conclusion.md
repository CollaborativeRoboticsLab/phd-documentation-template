## Conclusion

Contribution 1 delivers Capabilities2 as a ROS2-native framework for representing and executing robot capabilities in a way that is both standardised and extensible. Building on the original ROS Capabilities package, it replaces a static, launch-centric design with database-backed capability models, runtime registration, and a plugin-based runner architecture. These changes make the framework more suitable for contemporary HRI systems, where robot skills must be explicit enough for dependable control yet flexible enough to support adaptation, reuse, and higher-level planning.

The consolidated chapter also preserves the broader thesis framing around Prompt Tools and Capabilities2 Fabric. That retained material shows how the capability layer was intended to support a larger behaviour-based planning stack in which language-model prompts, execution-plan validation, and event-based capability chaining are all mediated through explicit capability definitions. Even though these surrounding subsystems were not part of the finalized Capabilities2 paper, they remain important for understanding the intended role of this contribution in the thesis.

The GPSFSM paper adds a further layer of evidence for this interpretation. It recasts Fabric as a generative partially specified finite state machine framework, makes the PromptTools pipeline more explicit, and reports benchmark and demonstration results for the combined stack. Those results suggest that the runner-based, event-driven capability layer introduced in Capabilities2 is a workable substrate for generative planning, particularly when paired with stronger cloud-based language models.

The chapter therefore shows that Capabilities2 is not merely a port of earlier work, but an infrastructure contribution that broadens how capability abstractions can be used. It supports descriptive robot interfaces, cross-platform portability, secure mediated access to subsystem behaviours, and emerging AI-assisted planning workflows. At the same time, the framework remains deliberately scoped: it avoids embedding a fixed world model and instead prioritises a clean extension surface for domain-specific specialisation.

Within the broader thesis, this contribution establishes the capability abstraction layer on top of which subsequent planning and behaviour-generation research can build. The next contribution can therefore assume a more explicit and reusable interface between high-level reasoning systems and the robot subsystems that ultimately execute behaviour.
