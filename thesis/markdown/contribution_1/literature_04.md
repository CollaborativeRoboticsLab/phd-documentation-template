# FSMs with LLMs

Finite State Machines (FSMs) remain attractive in robotics because they provide explicit states, explicit transitions, and a control structure that is comparatively easy to verify and debug [Using Finite State Machines in Introductory Robotics: Methods and Applications for Teaching and Learning]. For sequential tasks and safety-critical execution, this explicitness is valuable because failures can often be localized to a specific state, transition condition, or missing event. The difficulty is that conventional FSMs become rigid as tasks, contingencies, and interaction patterns grow more complex. This tension between explicit control and limited adaptability is the main reason recent work has started to combine FSM-based execution with Large Language Models (LLMs).

The literature can be understood as a graph with four connected themes. First, some work treats the LLM as a development-time assistant for editing or generating FSMs. Second, some work uses the LLM as a high-level planner whose outputs are grounded through FSM-like execution structures. Third, some work places FSM-LLM integration inside human-robot interaction settings, where language understanding and social interaction matter directly. Fourth, a broader neuro-symbolic line of work frames FSMs as one instance of a symbolic grounding layer that can constrain or explain the behavior of otherwise opaque neural models.

At the first node of this graph are studies that use LLMs to assist FSM engineering itself. The clearest example is [Can Large Language Models Help Developers with Robotic Finite State Machine Modification?], which investigates whether an LLM can modify existing robotic FSM code in response to natural-language requests. The contribution is not merely convenience. It suggests that FSM maintenance, which is traditionally slow and error-prone, can be partially lifted from low-level manual editing to instruction-guided synthesis, especially when paired with retrieval-augmented context. In a related direction, [Harnessing the Power of Large Language Models for Automated Code Generation and Verification] supports the broader claim that LLMs can reduce development overhead in code-centric robotics workflows, although these benefits depend on strong validation and contextual grounding.

The second node focuses on task planning and execution. Here the LLM is not primarily a coding assistant, but a system that interprets goals, decomposes tasks, and proposes action structure. A key limitation identified across this line of work is that raw LLM outputs are often not deterministic enough for long-horizon robotic execution [A Survey of Robot Intelligence with Large Language Models]. This is why serialized or structured state representations have become important. [Look Before You Leap: Using Serialized State Machine for Language Conditioned Robotic Manipulation] argues that LLM-generated serialized state machines can preserve the benefits of language-conditioned planning while making execution more deterministic for manipulation tasks. Related planning work such as [Semantic Intelligence: Integrating GPT-4 with A* Planning in Low-Cost Robotics] and [LLM-based Robot Task Planning with Exceptional Handling for General Purpose Service Robots] shows a similar pattern: LLMs are useful for semantic interpretation and plan proposal, but structured planners, explicit execution models, or runtime exception handling are still needed to make those plans dependable in the physical world.

Autonomous navigation provides a practical example of this architecture. In [Speech-Guided Sequential Planning for Autonomous Navigation Using Large Language Model Meta AI 3 Llama3], spoken commands are parsed into structured task parameters, and the robot then executes the resulting task through a staged control process rather than through unconstrained free-form generation. [LLM-Aided Autonomous Robot Navigation] follows the same general idea by using LLMs to interpret user intent while grounding movement in explicit navigation logic. These examples reinforce a broader point: FSMs and related state-based controllers remain useful because they translate linguistic intent into bounded execution stages.

The third node concerns human-robot interaction. LLMs substantially improve the robot's ability to interpret open-ended instructions, sustain dialogue, and adapt interaction to context [Exploring LLM-powered multi-session human-robot interactions with university students]. In assistive and socially interactive settings, this matters because user intent is often underspecified, sequential, and embedded in conversation rather than delivered as a clean command. [MindEye-OmniAssist: A Gaze-Driven LLM-Enhanced Assistive Robot System for Implicit Intention Recognition and Task Execution] extends this argument by showing how multimodal signals such as gaze can be combined with LLM reasoning to infer intent more flexibly than rigid pre-scripted interaction policies. However, [Understanding Large-Language Model (LLM)-powered Human-Robot Interaction] also indicates that richer language capability raises user expectations and can create failure modes when fluent dialogue is not matched by reliable logical behavior. From an FSM perspective, this means the state-based execution layer still has value as a stabilizing mechanism even when the interaction front-end becomes much more expressive.

The fourth node is the neuro-symbolic perspective. [Neuro-Symbolic Robotics] argues that robotics needs systems that combine the adaptability of learned models with the verifiability and interpretability of symbolic structures. This framing helps explain why FSMs continue to matter even when BTs, planners, and foundation models receive increasing attention. FSMs are not simply legacy control tools; they can serve as one form of symbolic scaffold through which LLM proposals are grounded, checked, and executed. The broader reasoning literature, including [AI Reasoning in Deep Learning Era: From Symbolic AI to Neural Reasoning Toward More General and Adaptive Intelligence], reinforces this view by showing that neural systems can exhibit powerful reasoning-like behavior while still lacking the explicit guarantees needed for safety-critical deployment.

This literature also makes clear that FSMs are not the only structure competing for this grounding role. [Automatic Behavior Tree Expansion with LLMs for Robotic Manipulation] shows that Behaviour Trees can be more modular and reactive than FSMs in some robotic settings, especially when policies must be repaired or extended incrementally. The comparison is therefore not whether LLMs should be paired only with FSMs or only with BTs. The more accurate conclusion is that LLM-based robotics is moving toward heterogeneous control architectures in which different symbolic substrates support different requirements. FSMs remain especially useful when deterministic sequencing, explicit transition logic, and inspectable failure handling are more important than the broader reactivity and compositional flexibility associated with BTs.

Across these four nodes, the literature converges on a consistent pattern. LLMs are effective at interpreting language, extracting semantic structure, proposing plans, and assisting developers, but they remain weak when left alone to produce reliable robot execution in dynamic environments [A Survey of Robot Intelligence with Large Language Models]. FSMs help by constraining execution into explicit stages, but they inherit the classic weaknesses of rigidity, scaling difficulty, and heavy maintenance when used in isolation [Using Finite State Machines in Introductory Robotics: Methods and Applications for Teaching and Learning]. The current research direction is therefore not to replace one with the other, but to use LLMs to increase flexibility around an explicit symbolic execution substrate.

From that perspective, the open problems are also clear. LLM-FSM systems still face hallucination, prompt sensitivity, computational overhead, weak transfer across domains, and unresolved safety concerns [Function Calling in Large Language Models: Industrial Practices, Challenges, and Future Directions] [A Survey of Robot Intelligence with Large Language Models]. In multi-agent or manufacturing contexts, these issues become even more visible because the controller must reason about capabilities, resources, and coordination under changing conditions [A Large Language Model-Enabled Control Architecture for Dynamic Resource Capability Exploration in Multi-Agent Manufacturing Systems]. The unresolved challenge is therefore the last mile between high-level linguistic competence and robust low-level execution. This is precisely the space where FSMs, serialized state representations, and other symbolic control models remain relevant.

Overall, the literature suggests a clear graph of dependency rather than a simple linear progression. LLMs improve how robot goals are specified, interpreted, and adapted; FSMs improve how those goals are executed, checked, and debugged; and neuro-symbolic approaches explain why combining both is more promising than relying on either alone. For this thesis, that graph is useful because it positions FSMs not as an outdated alternative to newer AI methods, but as one of the main structures through which LLM-driven robot behavior can be made operational, interpretable, and safer.
