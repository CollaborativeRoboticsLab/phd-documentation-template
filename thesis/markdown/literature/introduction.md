# Literature Review

This chapter provides a comprehensive overview of the literature, establishing the background for the research.

Section Focus 1 contains a comprehensive literature review on the robotic systems that can be used for HRI. First, the literature on behaviour-based systems is discussed. Then, literature about learning-based systems is addressed. After that, generative systems that utilise Large Language Models are discussed. The section also includes literature on Vision Language Models and how generative robotic systems work with them, followed by Vision Language Action models and Vision Language Navigation models.

Then, long-horizon task planning is discussed in Section Focus 2.

Finally, literature on socially aware navigation is discussed in Section Focus 3.
