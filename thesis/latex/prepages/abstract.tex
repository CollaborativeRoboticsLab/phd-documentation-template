{\noindent \huge \bf Abstract}\\[20mm]

To keep up with dynamic and social humans, robots need to be able to monitor the environment and adjust themselves dynamically. Although various studies have been conducted on robotic planning systems for long-term task planning, dynamic replanning, and socially aware navigation, only a few have focused on mimicking human attention, and even fewer have utilised this for robotic social interaction. This research advances the field by proposing a generative behaviour-based planning framework with a robotic attention mechanism for environmental sensing. The key contributions of this research include a generative behaviour-based planning system, called \textit {Fabric}, that utilises LLMs for dynamic replanning. The Fabric consists of subsystems called the Capabilities2 framework for behaviour management, the Capabilities2 Fabric for event-based behaviour chaining, and prompt tools for LLM communication. The Capabilities2 framework is an enhanced reimplementation of an early capabilities package, allowing for behaviour starting, stopping, triggering, and chaining, which enables enhanced adaptability and more human-like social behaviours in robots. Capabilities2 fabric supports XML-based execution plan parsing and capability control, evolving the capabilities2 framework into a behaviour-based planning system. The Prompt Tools system allows interactions with the LLM in a manner optimised for robotic systems. The Fabric has been evaluated based on the functionality of both generative and non-generative behaviour-based planning systems. Future work includes evaluating the system's performance and comparing it against state-of-the-art (SOTA) systems, such as Behaviour Trees. By bridging the gap between theoretical understanding and practical implementation, this research provides a foundational framework for generative behaviour-based planning with robot attention, offering new insights into how robotic systems can evolve into dynamic entities, effectively enhancing human- robot interactions.
